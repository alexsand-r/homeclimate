# Шпаргалка по Claude Code: Команди та економія бюджету

Цей файл допоможе тримати під рукою основні команди розширення **Claude Code** у VS Code та правила, які збережуть баланс API.

---

## 🛠 Основні слеш-команди в чаті

Вводяться безпосередньо в поле чату Claude Code:

* **`/clear`** — повністю очищає історію поточного діалогу. **Головна команда для економії.** Використовуй щоразу, коли закінчив одну задачу (наприклад, зверстав секцію) і переходиш до наступної.
* **`/compact`** — стискає поточну історію розмови у короткий підсумок. Корисно, якщо задача ще не завершена, але чат став занадто довгим і почав дорого коштувати.
* **`/model`** — відкриває меню вибору моделі та рівня її роздумів (Effort).
* **`/cost`** — показує, скільки токенів і грошей (у доларах/центах) було витрачено за поточну сесію.
* **`/status`** — перевіряє статус підключення до твого API-акаунту Anthropic, активну організацію та поточну модель.
* **`/init`** — автоматично аналізує проєкт і створює файл `CLAUDE.md` з інструкціями для агента (правила проєкту, стек технологій, мова спілкування).
* **`/help`** — виводить повний список усіх доступних команд та гарячих клавіш.

## 💰 Як максимально економити баланс ($5)

1. **Обирай правильну модель під задачу:**
   * **Haiku 5.5 (Medium)** — для 80% задач: верстка HTML/Tailwind, правки стилів, дрібні зміни в JS, перейменування файлів. Коштує копійки.
   * **Sonnet 5.5 (Medium)** — коли Haiku не справляється або потрібна складніша логіка на JavaScript.
   * **Opus 5.5** — лише для критично складних багів або архітектури.
2. **Не тягни старий контекст (`/clear`):**
   * З кожним новим повідомленням Claude перечитує весь попередній чат. Чим довший чат — тим дорожчий кожен наступний запит. Завершив блок — написав `/clear`.
3. **Відкріплюй зайві файли:**
   * Слідкуй за панеллю над полем вводу: якщо там висять прикріплені файли (наприклад, `README.md`), які вже не потрібні для нового завдання — закривай їх хрестиком `×`.
4. **Став конкретні задачі замість загальних:**
   * ❌ *Погано (дорого):* «Перевір весь мій сайт і скажи, що можна покращити». (Агент прочитає всі файли в проєкті).
   * ✅ *Добре (дешево):* «Додай у `index.html` після рядка 580 секцію відгуків за зразком карток вище, використовуючи Tailwind v4».
5. **Комбінуй з GitHub Copilot (Free):**
   * Дрібні правки в 1–2 рядки, автодоповнення класів Tailwind чи базові підказки роби через безкоштовний Copilot, а Claude Code викликай для створення цілих секцій або роботи з кількома файлами одночасно.

## 🇺🇦 Як закріпити українську мову назавжди

Щоб не просити Claude відповідати українською в кожному новому чаті після `/clear`, створи в корені проєкту файл **`CLAUDE.md`** і додай туди такий текст:

```markdown
# Правила проєкту
- Завжди спілкуйся, пояснюй дії та пиши звіти виключно українською мовою.
- Стек проєкту: Vite, HTML5, Tailwind CSS v4, Vanilla JS.
- Пиши чистий, семантичний код без зайвих бібліотек.
```
